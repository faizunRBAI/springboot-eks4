## Key decisions
- `ddl-auto: validate` — schema is owned by Flyway, Hibernate never alters it
- `open-in-view: false` — avoids lazy-load issues in a REST API
- `ItemService` injected as `required=false` into controller — handles database=none gracefully
- No NAT gateway — nodes reach ECR via public subnets (blueprint design, ~$65/mo saving)
- RDS password generated by Terraform `random_password` (alphanumeric, length=32), not a CI secret
- RDS PostgreSQL 16, sslmode=verify-full with RDS global bundle from the image

## Known-good versions (do not downgrade)
- Spring Boot parent: 3.5.16
- postgresql driver: 42.7.13 (overrides BOM to patch CVE)
- aws provider: ~> 5.82.0 (pinned below 5.83.0: password write-only change breaks output)
